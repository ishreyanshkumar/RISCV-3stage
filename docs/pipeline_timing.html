C1–C3 Normal sequential flow: ADD (R-type) → LW (I-type load) → BEQ (B-type branch) fill IF/ID/EX/WB in lockstep. No hazards. wb_alu_to_reg=1 fires at C4 when ADD reaches WB; wb_dest_reg_sel=x3.
C6–C8 branch BEQ evaluates at C7, condition is true → branch_taken=1, next_pc=0x40. branch_stall asserts for 2 cycles (C7–C8) driven by wb_branch_i / wb_branch_nxt_i. Both mis-fetched instructions are replaced with NOPs and discarded — wb_alu_to_reg=0 on both, no RF write occurs. wb_stall=1 for both cycles prevents spurious register writes from WB.
C10–C11 JAL JAL executes at C11, computes next_pc = pc + offset = 0x80, writes return address pc+4 = 0x44 to x1 (link register). One NOP bubble flushed at C12. Pipeline resumes from 0x80.
C13 SW Store word: wb_mem_write=1 drives wb_write_address = r5+imm, wb_write_data = r6_val, wb_write_byte = 0xF (full 32-bit word). No wb_alu_to_reg — store instructions never write the register file.
Forwarding At C4, LW operand forwarded from WB back to EX via the reg_rdata1/2 mux: (!wb_stall && wb_alu_to_reg && wb_dest_reg_sel == src) selects wb_read_data or wb_result over the stale register-file read.
